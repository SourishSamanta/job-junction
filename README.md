# Job Junction 🤝

A full-stack job portal application connecting recruiters and job seekers.

[![GitHub Repo](https://badgen.net/badge/GitHub/Repo/blue?icon=github)](https://github.com/SourishSamanta/job-junction.git)
[![License](https://img.shields.io/github/license/SourishSamanta/job-junction.git?color=green)](https://github.com/SourishSamanta/job-junction.git/blob/main/LICENSE)


## 🚀 Features

* **User-friendly interface:**  Intuitive design for both job seekers and recruiters.
* **Robust search functionality:** Easily find relevant jobs or candidates.
* **Secure authentication:**  Protect user data with secure login and registration.
* **Comprehensive profiles:**  Create detailed profiles to showcase skills and experience.
* **Advanced filtering:** Refine search results based on specific criteria.

## 💻 Tech Stack

* **Frontend:** React, Tailwind CSS, Vite
* **Backend:** Node.js, Express.js, MongoDB (or other database as specified)


## 📦 Installation

This project consists of a frontend and a backend.  You'll need to clone the repository and install dependencies for each separately.

**1. Clone the repository:**

```bash
git clone https://github.com/SourishSamanta/job-junction.git
cd job-junction
```

**2. Backend Installation:**

```bash
cd backend
npm install
# Create a .env file in the backend directory and configure your database credentials.  See the backend/.env.example for details.
```

**3. Frontend Installation:**

```bash
cd ../frontend
npm install
```

## Usage 🛠️

1. **Start the backend:**

```bash
cd ../backend
npm run start
```

2. **Start the frontend:**

```bash
cd ../frontend
npm run dev
```

The project is structured into two main directories: `backend` and `frontend`.

* **frontend/**: Contains the client-side code, built using React.
